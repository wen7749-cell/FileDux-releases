# FileDux for macOS

Downloads of FileDux, a dual-pane file manager for macOS.

- Download the latest **.dmg** from [Releases](https://github.com/wen7749-cell/FileDux-releases/releases/latest).
- Installed copies update themselves from here (`latest.json`, signed with the FileDux update key).

FileDux is signed with an Apple Developer ID and notarized by Apple.
